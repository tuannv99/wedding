# Nhạc nền

Tên file được cấu hình trong `lib/wedding.ts` → `wedding.music.src` / `wedding.music.title`.
Hiện đang dùng: `mot-doi.mp3` ("Một Đời").

- Nếu file lỗi hoặc chưa có, nút nhạc ở góc phải sẽ tự động ẩn.
- Nhạc không tự phát khi tải trang; chỉ phát khi khách bấm nút nhạc hoặc bấm "MỞ THIỆP".
- Nên nén xuống dưới ~4MB (128 kbps) để khách mở bằng 3G/4G không tốn dung lượng và vào nhanh.
- Nhớ dùng bản nhạc có bản quyền hợp lệ.
